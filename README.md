# Ember Drift

An arcade survival game. Survive round after round, build an arsenal of 13 weapons, awaken them with paired passives, and beat a one-on-one boss every fifth round.

**Play:** https://jrmagner1.github.io/ember-drift/

**Install on iPhone:** open the link in Safari, tap Share, then Add to Home Screen. It opens full screen and works offline after the first launch.
